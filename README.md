# Лабораторная работа № 2. Одномерные массивы

Консольная программа на C++ для работы с массивом из 100 целых чисел.
Массив можно заполнить вручную или случайными числами от −99 до 99.

Программа сравнивает пять сортировок, находит минимум и максимум,
выполняет линейный и бинарный поиск и меняет элементы местами по индексам.

## Сборка и запуск

На Windows с g++:

```powershell
g++ -std=c++17 main.cpp -o main.exe
.\main.exe
```

На Linux или macOS:

```bash
g++ -std=c++17 main.cpp -o main
./main
```

## Индивидуальное задание № 26

Выберите пункт 8 в меню. Программа проверит, отсортирован ли массив
по неубыванию. Если элемент меньше предыдущего, программа выведет
индекс первого нарушения. Индексы начинаются с нуля.
